# 🎬 SubDL Subtitles for Kodi

[![Kodi Version](https://img.shields.io/badge/Kodi-19%20%7C%2020%20%7C%2021-blue.svg)](https://kodi.tv)
[![License: GPL v2](https://img.shields.io/badge/License-GPL%20v2-yellow.svg)](LICENSE.txt)
[![Language: Vietnamese](https://img.shields.io/badge/Language-Vietnamese-red.svg)](#)

**SubDL for Kodi** là một addon mạnh mẽ cho phép tìm kiếm và tải phụ đề phim, series truyền hình trực tiếp từ thư viện khổng lồ của [SubDL.com](https://subdl.com). Dự án được tối ưu hóa đặc biệt cho người dùng Việt Nam với giao diện tiếng Việt hoàn chỉnh và cơ chế tìm kiếm thông minh.

---

## ✨ Tính năng nổi bật

- **🔍 Tìm kiếm thông minh**: Tự động nhận diện tên phim, mùa (season) và tập (episode) bằng TMDB API.
- **🇻🇳 Tối ưu tiếng Việt**: Hỗ trợ tìm kiếm phụ đề tiếng Việt chuẩn xác nhất.
- **🌍 Đa ngôn ngữ**: Khả năng ghi đè ngôn ngữ tìm kiếm (Auto, VI, EN, FR, DE, JA, KO, ZH).
- **🚀 Tốc độ cao**: Cơ chế giải nén file ZIP thông minh, tự động lọc bỏ file rác (quảng cáo) để lấy đúng file phụ đề.
- **🔑 Linh hoạt API**: 
  - Hỗ trợ **Community Keys**: Cài là chạy ngay không cần cấu hình phức tạp.
  - Hỗ trợ **Personal Keys**: Cho phép người dùng tự nhập Key cá nhân để đảm bảo ổn định và riêng tư.

## 🛠 Hướng dẫn Cài đặt

### Cách 1: Cài đặt từ tệp Zip
1. Truy cập vào mục [Releases](#) của repository này.
2. Tải về file `.zip` mới nhất (ví dụ: `service.subtitles.subdl-1.0.0.zip`).
3. Mở Kodi, đi tới **Add-ons** > **Install from zip file**.
4. Chọn tệp vừa tải về để cài đặt.

## ⚙️ Cấu hình (Configuration)

Để addon hoạt động ổn định nhất, bạn nên thiết lập API cá nhân:

1. Vào **Add-ons** > **Subtitles** > Chuột phải vào **SubDL** > **Cấu hình (Settings)**.
2. **Cấu hình API**: 
   - Bật **Dùng API Key cá nhân**.
   - Nhập SubDL API Key lấy từ [SubDL Panel](https://subdl.com/panel/api).
   - Nhập TMDB API Key lấy từ [TheMovieDB Settings](https://www.themoviedb.org/settings/api).
3. **Ngôn ngữ phụ đề**: 
   - Tại mục **Ngôn ngữ tìm kiếm ưu tiên**, chọn **Tiếng Việt (VI)** để addon luôn ưu tiên tìm sub Việt thay vì phụ thuộc vào cài đặt hệ thống của Kodi.

---

## 📖 Hướng dẫn Sử dụng

1. Mở một bộ phim hoặc tập phim bất kỳ.
2. Nhấn vào biểu tượng **Subtitles** (Phụ đề) trên trình phát.
3. Chọn **Download subtitle...** (Tải phụ đề...).
4. Chọn dịch vụ **SubDL** từ danh sách.
5. Danh sách phụ đề sẽ hiện ra, chỉ cần chọn bản phù hợp và tận hưởng!
